# AI4S 出题工作台

先看用户想推进到哪里。有题包时读取实际题面、作答文件、评分器和来源。只有材料或候选时先明确一个可检验的研究目标。把附件和论文读作证据，作答限制由题面和用户给定。

运行本 skill 同级的 [workbench.py](scripts/workbench.py)，用 Python 3.9+。需要命令或字段时读[本地用法](references/contract.md)。

- **题面先做减法。** `init` 建最小规格。`brief` 默认只出「问题、解答、约束」。问题交代目标和可见输入，解答交代提交物和格式，约束交代必要条件与主评分。标准答案保存在组织方。原有题面可用 `--legacy-brief` 接入。精简旧题时先核对它的输入、交付和判分，再用相同契约生成新题面。
- **根据实际阅读问题加内容。** 先看首次读题的人是否能说清拿到什么、要做什么、怎么交。遇到术语或场景障碍时只补相关背景，有格式歧义时给一条公开示例。`--add background` 和 `--add diagnostics` 可分别展开。解题必需的定义、单位、数据出处位置和适用条件写入三栏正文。对照两个版本时固定输入文件、评分规则和工具条件。
- **科学审题。** 逐条核对实验对象、条件、原始位置和处理。区分实测、实测派生、模拟和文档声明。写出能排除的替代解释、当前数据能辨认到什么程度、一个简单基线以及它的真实表现。按[科学核查步骤](references/science.md)记录。`audit` 验证文件、派生链和记录；领域判断要回原始证据，程序报告中的作者自报复核要标明出处。
- **评测。** 逐项写 `rule` 或 `rubric`。前者给单位、误差方向及确定性算法，并验证真实的评分器和边界。后者给可观察的等级依据，用同一批匿名提交独立双评。主指标和诊断项各自记录，混合评测按题目已确定的规则汇总。有单独授权时，用 `replay` 调用已审阅的本地 Python 评分器。
- **模拟考试。** `freeze` 从显式清单复制选手所见并锁定摘要。环境按题面限制实际隔离。保留不同模型的独立会话和首次作答，沿用已确定的多轮证据安排。要双评方法说明时，`judge-packet`、`judge-template`、`reconcile` 固定材料、验证引文和列出分歧。使用付费 API、发送材料或发布询题需有对应的用户授权。

交付时说明哪些检查实际跑过，哪些科学结论仍受限，以及分数来自哪份作答和哪一版规则。草稿的空白是待办，审题记录中的真实失败应保留。

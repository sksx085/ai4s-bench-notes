# 科学核查

**把目标写成可观察的结果。** 记录被预测的对象、实验条件、观察窗口、单位和一条实际观测的独立单位。举例说，零场主磁弛豫时间达到 100 秒的温度，可通过该样品的实际衰减记录来约束。扫场开环温度另有实验定义。

**记录主张和可反驳它的证据。** 每项主张对应可定位的资料、原始表列和必要转换。例子是同一份补充表同时有撤场和小幅方波得到的时间。它们有不同的测量条件，需要分别登记。只有同协议复测时，才估计复测误差。

**问目前能辨认到哪一步。** 对逆问题给出仍相容的结构、参数或机制，并说明哪项观测能打破等价性。对预测问题用独立实验留出、方向与幅度，检查模型是否仅靠家族标签、干预顺序或表格键就能推断。删去非必要信息后，用一个人能读懂的例子核对交付。实验没有支持一个精确数时，留区间或注明当前任务的点值证据不足。

**用两类对照挑战题目。** 先查只用允许资料的常量、最近邻或简单物理方法。再跑本领域会实际采用的常规方法。若已预设难度门槛，记录实测结果及该门槛的适用范围。对照的运行记录要有题单、误差、分母和条件。保留失败实例。

**把判分与审题分开验证。** 用已知正确、边界和无效的提交复放程序结果。方法说明若要计分，针对方案可行性或证据有效性给出分级依据并双评。给每份提交留理由和分歧。双评一致性可以暴露量表含糊程度，是否与专家对齐需要另外有参考判定。

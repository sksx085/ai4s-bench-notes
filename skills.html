AI4S_chem_dataset

ai4s-chem-datasetv0.1.0

把化学论文、补充材料、数据库或计算记录整理成可留出、可自动评分的数据集。

适用场景
需要制定采样和切分规则、核查真值，或为预测任务设计提交格式和打分细则。
预期交付
数据集规格，包含来源与归属、独立留出组、误差与区间评分、基线和复核记录。包内含规格模板。
安装说明

核对 ZIP 的 SHA-256。完整解压后，把 ai4s-chem-dataset/ 文件夹放进 Codex 的 Skills 目录。开启新会话，在消息中调用 $ai4s-chem-dataset。

调用示例

请用 $ai4s-chem-dataset 审阅这批谱图的归属证据，定义整组留出、点值与区间的入组条件，并写出主分和分母。

AI4S 科研挑战设计

ai4s-challenge-designv0.1.0

把论文或科研数据整理成逆问题、逆向设计或优化任务，也可用来审阅已有题目。

适用场景
有论文图表、数据文件或出题初稿，需要判断现有证据支持哪些问题。
预期交付
题面草案、允许的等价解、判分规则和独立试做清单。包内含题面与作者记录模板。
安装说明

需要 Python 3.11 或更新版本。完整解压后，在包目录运行 python3 install.py --check 校验。校验通过后运行 python3 install.py，然后在新的 Codex 会话中调用 $ai4s-challenge-design。

安装目录、Windows 命令和版本替换说明见包内的 INSTALL.txt。

下载 SHA-256 校验文件
调用示例

AI4S 评分规则

ai4s-scoring-rulev0.1.0

规定一道科学题的分数怎么构成。采分点要落在可单独失败的维度上，权重按对结论的重要性分配，对外用百分制。

适用场景
出题时写计分，改总分口径，或核对题面、评分器和结果页是不是同一条规则。
预期交付
一张计分合同。每行是一个采分点，写明维度、部位、通行准则、权重、0 分锚和 100 分锚。不提供某一学科的判据。
安装说明

核对 ZIP 的 SHA-256。完整解压后，把 ai4s-scoring-rule/ 文件夹放进 Codex 的 Skills 目录。开启新会话，在消息中调用 $ai4s-scoring-rule。

下载 SHA-256 校验文件
调用示例

请用 $ai4s-scoring-rule 审阅这道题的计分。列出维度和采分点，按对结论的重要性加权，并核对题面与结果页是否同一条规则。

催化机制反演出题

catalysis-inverse-benchv0.1.0

用动力学、原位表征和对照实验约束候选机制，设计可判分的干预选择或盲测预测任务。

适用场景
多个机制能解释已有观测，需要设计判别实验，或已有独立留出的实测结果可供检验。
预期交付
候选机制与观测的对应关系、拟议干预的判别依据，以及按现有证据可写到的题面。
安装说明

把解压后的 catalysis-inverse-bench/ 整个文件夹放进当前 Codex 会话可用的 Skills 目录，保留其中的 SKILL.md、模板和参考资料。开启新的会话后调用 $catalysis-inverse-bench。

下载 SHA-256 校验文件
调用示例

从材料到可复核的任务

  1. 提供原始依据。 随材料注明图表编号、数据文件、实验条件和单位。机制比较附上可见对照，并说明哪些记录用于留出验证。
  2. 检查产物。 核对题面能否独立作答、等价解是否受理，以及评分规则能否识别一种实质错解。查看 Bench 质量指标。
  3. 将已有题目续接到项目。 已安装 TaskFoundry 时，可在现有项目中提供题面、参考解和核验记录，再指定出题、复盘或重设计阶段。

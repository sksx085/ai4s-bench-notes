# NMR 位移预测与不确定度

本方案评估模型能否从分子结构、采集条件和题包内允许使用的谱学证据，预测留出位点的 ¹H、¹³C 化学位移。每个位点提交一个点值和一个等尾 95% 预测区间。按核种用区间分数比较区间质量，用 MAE 比较点值精度，同时记录覆盖率、区间宽度、解题时间和评分时间。

## 1. 预测对象与抽样

一个目标是一个指定样品、采集条件和核种下，经归属的一条信号的化学位移中心（ppm）。等价原子共享一条信号时以组计数。不等价的同碳双氢仅在独立归属清楚时分别计分。题目按明确编号的位点提交，未知归属列在候选表中，待复核后再进入留出集。

第一批至少有 10 个独立测试母分子，有数据时扩到几十至几百个。按芳香族、杂环、稠环、桥环、螺环、多官能团和含卤结构分层抽样。一种分子可以同时有多个类别标签，分层数因此可重叠。同一母分子的复测、盐型、不同条件以及修订版本统一分组；近似同系物和同一来源的复用数据一并检查。开发、调区间和最终测试按母分子分开，需要检验陌生骨架时额外按骨架或论文分组。模型使用的结构、条件和可见谱学证据在每题的公开清单中列明。

近期样本优先从 2026 年 11 月 1 日之后首发的 ChemRxiv 论文及 SI 复核。规模和类群覆盖不足时，另纳入可追溯的公开实测来源。候选谱表必须能对应结构、位点和采集条件，才进入逐位点评测。目前 DELTA50 的 14 个有实测列的候选可用于首批复核，不同来源的场强、温度、溶剂和浓度分别记录。近期已找到的配对峰表中，缺原子编号的部分先作为选样材料。[论文更新](../papers.html) · [DELTA50](https://www.mdpi.com/1420-3049/28/6/2449)

## 2. 建立留出真值

逐条保留论文或数据集 ID、版本、SI 页码、化合物号、谱图编号、原子或等价组映射、原始报告字符串、核种、溶剂、温度、场强、浓度和参照。未报告的条件记为缺失。记录原值的显示精度、峰型、积分、耦合及赋值证据。对由同一原始谱导出的表格或出版版本保留共同的来源标识，以便去重。交换氢和相邻重叠信号须核对来源条件后再决定是否纳入。[IUPAC 化学位移参照规范](https://publications.iupac.org/projects/2003/2003-006-1-100.html)

| 标签 | 入组规则 | 计分用途 |
| --- | --- | --- |
| 明确点值 | 原作者给出可核位点的信号中心 | 主评测，保留报告精度 |
| 单一峰型窗口 | 证据支持一组已归属且分辨清楚的标准多重峰，例如一组分离的双峰或三重峰。上下界对应该组 | 记录原窗口，取两端平均作为派生点值，另报只使用原报点值的结果 |
| 仅区间 | `m` 的报告窗口、重叠、几个峰合并为一条记录，或无法独立确认哪条线属于目标 | 保留作质检和复核，暂不计主 MAE、区间分数或覆盖率 |
| 暂不纳入 | 位点对应有争议、异构体混合、条件无法对齐，或只给计算、模拟值 | 保留排除依据 |

即使标成 `m`，只要原作者明确给出一条独立归属信号的点值，可按明确点值入组。氢谱的多重峰范围记录裂分线覆盖的谱轴范围。95% 预测区间描述模型对**信号中心**的预测不确定度。主评测在运行前冻结目标键、数值、条件、归属模式和排除清单。按核种和结构类别报告入组率及排除原因，便于观察重叠较多的分子是否被系统性剔除。[NIST 对单次观测预测区间的说明](https://www.itl.nist.gov/div898/handbook/pmd/section5/pmd512.htm)

## 3. 数据误差与可达精度

把以下不确定度来源分开记录。报告到 0.01 ppm 且确认采用四舍五入时，单纯舍入的误差界是 0.005 ppm。对同一份原始 FID 重新拾峰，反映处理或拾峰差异；同一管样品按相同协议重新采集，反映技术重复性；同条件的独立配样、跨天或跨实验室复测，包含制样和再现性影响。归属不确定、参照偏差及溶剂或温度引起的变化另记。复测范围与最终预测对象的采集协议对齐。[NIST TN 1297 测量不确定度](https://www.nist.gov/pml/nist-technical-note-1297)

对满足同结构、同位点、同核种和同条件的重复测量，预先选定两次独立读数，记 `d = y1 − y2`。分别报告 ¹H、¹³C 的配对母分子数、位点数、平均绝对差和高分位绝对差。多次测量不拆成若干独立样本。可以另报用其它复测的中位数预测一次留出复测的 MAE，作为经验复测基线。

- **不依赖正态假设的下界。** 如果两次同条件读数有相同的边际分布，且点预测 `p` 对两次都相同，则 `|y1 − y2| ≤ |y1 − p| + |y2 − p|`。在该复测人群中，平均绝对差的一半可估计单次观测点预测期望 MAE 的下界。
- **正态模型下的噪声尺度。** 若同一条件档内的两次误差独立、同方差、近似中心正态，且预测目标是一次未来测量，可以用 `sd(d)/√2` 估计单次测量标准差 `σ`。知道该位点真实测量中位数的理想预测器，其期望 MAE 约为 `sd(d)/√π`。若中心和 `σ` 均已知，仅考虑测量噪声时，等尾 95% 区间的宽度约为 `3.92σ`。需报告复测分母和假设，配对差会消掉共同偏差。[NIST 关于覆盖系数的说明](https://www.itl.nist.gov/div898/handbook/pmd/section5/pmd512.htm)

在缺少匹配复测的层，量级标记为待估。样本中的最低模型 MAE、报告精度和单份谱的峰宽各有自己的含义。复测结果用于解释新测量上的可达精度，评分仍直接用冻结的留出值，不从模型误差中扣除噪声估计。

## 4. 选择区间分数

主方案采用**等尾 95% 预测区间的 Winkler 区间分数**。目标对应观测分布的 2.5%、50% 和 97.5% 分位数，中位数与绝对误差匹配。在同一 ppm 尺度上，区间分数同时惩罚区间太宽和漏掉观测，且上漏、下漏的距离权重相等。等尾区间可以在点预测两侧具有不同宽度。[Gneiting 和 Raftery，区间分数](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf) · [Brehmer 和 Gneiting，等尾区间](https://doi.org/10.3150/20-BEJ1298)

| 方案 | 衡量什么 | 本评测用法 |
| --- | --- | --- |
| 95% 区间分数 | 预测区间的宽度，以及真值落在区间外时的距离 | 主指标，配合覆盖率和平均宽度解释 |
| MAE | 点预测与参考值的平均绝对差 | 与区间结果并列，分别报 ¹H 和 ¹³C |
| 非对称绝对损失（ASL） | 给低估和高估不同代价，相应地把点预测推向某一个分位数 | 留给有明确代价差异的决策场景。当前评测在 ppm 尺度对两个方向等量处理 |

如果点损失写成 `w_under·max(y−p,0) + w_over·max(p−y,0)`，最优点预测在分位数 `w_under / (w_under + w_over)` 上。低估代价是高估的两倍时，最优点预测是约第 66.7 百分位数。区间分数可写成上下尾两个分位数损失的组合，分别检验两侧边界。[Gneiting，点预测的选择](https://doi.org/10.1198/jasa.2011.r10138) · [Gneiting 和 Raftery，分位数与区间预测](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

## 5. 作答格式与判分

公开清单列出每个待预测键 `(sample_id, nucleus, site_id)`。不同采集条件使用不同的样品记录 ID。测试提交 `prediction.csv`，各位点一行，三列数值单位均为 ppm，无单位后缀。

```csv
sample_id,nucleus,site_id,point_ppm,lower95_ppm,upper95_ppm
DEMO-01,1H,H7,7.20,7.10,7.30
```

`nucleus` 使用 `1H` 或 `13C`。三列数值均须有限，并满足 `lower95_ppm ≤ point_ppm ≤ upper95_ppm`。行序不限。先逐键校验，重复、未知、缺行、非有限数或上下界颠倒标为无效提交，单独留档；解析失败不替换成某一科学分数。预测区间的两端均算覆盖。格式和评分使用未提前舍入的提交数值。

对冻结实测值 `y`、点预测 `p`、下界 `L` 和上界 `U`，每个位点计算下列量。

```python
abs_error = abs(p - y)
width = U - L
below = y < L
above = y > U
covered = L <= y <= U
interval_score95 = width + 40 * max(L - y, 0) + 40 * max(y - U, 0)
```

例中若参考为 7.25 ppm，点误差为 0.05 ppm，区间分数为 0.20 ppm。若参考为 7.34 ppm，区间上侧漏掉 0.04 ppm，点误差为 0.14 ppm，区间分数为 1.80 ppm。区间分数与 MAE 越低越好。只看覆盖率时，加宽所有区间可以人为提高覆盖率；区间分数把宽度和漏报代价同时纳入。[区间分数推导](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

## 6. 汇总、复核与计时

¹H、¹³C 各自汇总。每个母分子内先算该核种各可计位点的均值，再对有该核种数据的母分子等权平均。按相同口径报告区间分数、MAE、覆盖率、平均区间宽度和上下侧漏报比例，另列各核种的母分子数、位点数及上下侧漏报次数。按结构类别、标签模式和采集条件查误差来源。在同一核种内比较主要成绩，避免把两个核种差异较大的 ppm 尺度直接合并。

对两个模型的差异，按母分子成组做配对重采样，每次两家使用同一批母分子。共享骨架或论文的记录较多时，增加对应的成组敏感性分析。10 个母分子足以开始试跑，95% 覆盖率仍需更多相对独立样品来判断。模型的 95% 预测区间指逐位点覆盖；汇总 MAE 的统计区间属于另一项报告。相邻位点的差值如另设区间任务，应要求模型直接提交差值分位数或联合预测，便于保留同谱位点间的相关性。

每次运行记录题包、标签表、判分器版本、模型版本、工具、预算和硬件配置。用单调时钟分别计时。

| 字段 | 起止点 | 解释 |
| --- | --- | --- |
| `solve_elapsed_s` | 启动作答请求至收到完整提交 | 模型作答的墙钟时间。远程请求可包含传输和服务端排队，已知的分项耗时可另外列出 |
| `grade_elapsed_s` | 开始读取已封存的提交至评分结果写出 | 包含格式校验、计算和结果写出。评分环境固定 |

首轮、重试、输出截断和运行故障分别记录。主表把各核种的误差、区间表现与两类耗时并列，时间保持独立单位。在完整跑一次前，先用覆盖边界、上下两侧漏报、极宽区间、无效键以及分子位点数不平衡的例子复核评分器。保存冻结题单与逐位点评分输出，使第三方能重新汇总。

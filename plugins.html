AI4S 出题工作台

ai4s-task-workbenchv0.2.0Codex

用「问题、解答、约束」生成精简题面，按需补背景。也可核查实验证据、提交格式和判分。

安装到 Codex

核对 SHA-256 后解压。用解压目录的实际路径运行以下两条命令。

codex plugin marketplace add "/实际路径/ai4s-workbench-marketplace-0.2.0"
codex plugin add ai4s-task-workbench@ai4s-bench-notes

开启新会话，选择 AI4S 出题工作台。运行本地脚本需要 Python 3.9 或更新版本。

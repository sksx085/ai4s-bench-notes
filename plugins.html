AI4S 出题工作台

ai4s-task-workbenchv0.3.0Codex

根据科研材料生成出题骨架，或精简已有题面。题面使用「问题、输入、输出、约束、精度」五栏，计分或排名时加「评分」。

在终端运行这一行即可安装。

codex plugin marketplace add sksx085/ai4s-bench-notes && codex plugin add ai4s-task-workbench@ai4s-bench-notes

安装后打开新 Codex 会话。运行插件脚本需要 Python 3.9 或更新版本。

更新 Git 安装的插件 
codex plugin marketplace upgrade ai4s-bench-notes
